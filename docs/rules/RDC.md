# RDC - Reset-domain crossings, asynchronous reset behavior and coordination

One table row per catalogued rule (titles must match `catalog.json`; a unit test checks this). Add a section
per rule below the table when it is specified: trigger, exemptions, severity policy, evidence, tests.

| ID | Required check |
|---|---|
| `RDC-001` | Identify reset sources, polarity, synchronous/asynchronous nature |
| `RDC-002` | Unconstrained or unknown reset source / domain |
| `RDC-003` | Asynchronous reset deassertion not synchronized to receiving clock |
| `RDC-004` | Data crosses between different reset domains on the same clock |
| `RDC-005` | Data crosses between independently reset domains on different clocks |
| `RDC-006` | Reset synchronizer has too few stages, inappropriate logic or fanout |
| `RDC-007` | Reset control generated in an unrelated clock/reset domain |
| `RDC-008` | Reset reconvergence or conditional reset topology |
| `RDC-009` | Reset gating/muxing that may glitch |
| `RDC-010` | Register partially reset while feeding other reset-sensitive logic |
| `RDC-011` | Unmodeled reset sequencing dependency |
| `RDC-012` | Retention/isolation/power-intent reset rules |
| `RDC-013` | Analog recovery/removal, minimum reset pulse width and physical metastability |
| `RDC-014` | Reset assertion glitch or pulse-width risk |
| `RDC-015` | Reset deassertion synchronizer clock mismatch |
| `RDC-016` | Reset synchronizer stage fanout to logic |
| `RDC-017` | Reset mux/gate select from different reset domain |
| `RDC-018` | Reset tree reconvergence after independently synchronized release |
| `RDC-019` | Reset fanout into functional asynchronous set/clear controls |
| `RDC-020` | Partial reset of packed state and dependent control |
| `RDC-021` | Power-on versus functional reset domain conflict |
| `RDC-022` | Reset generated by data flop in another clock/reset domain |
| `RDC-023` | FIFO and handshake reset release sequencing |
| `RDC-024` | Reset request/acknowledge sequencing across domains |
| `RDC-025` | Interface outputs during only one side reset |
| `RDC-026` | Asynchronous set and reset used together |
| `RDC-027` | Reset-domain false-path exception does not imply safety |
| `RDC-028` | Reset polarity and synchronization assumptions across hierarchy |
| `RDC-029` | Retention or isolation reset boundaries when power intent provided |
