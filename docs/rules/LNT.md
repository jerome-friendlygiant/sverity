# LNT - Semantic, structural and synthesizability lint

Titles must match `catalog.json` (a unit test checks this). The specification bullets below are the contract each rule is tested against
(`tests/fixtures/<RULE-ID>/`: good, bad, boundary, hierarchy/unknown cases). Rules marked *slang* map slang's own diagnostics (by option name
or error code, see `src/frontend/slang_rule_map.cpp`); nothing slang reports is dropped. A rule with a `gap` in `catalog.json` is Partial; gaps are not repeated here.

## Specification

- **LNT-001** — syntax, preprocess or elaboration error reported by slang (any error not mapped to another LNT rule); load failures. Exempt: none. Severity: FATAL for a load failure or an elaboration error summary, ERROR per slang error. Unknown: analysis scope INCOMPLETE; no rule result is trusted on an erroneous design.
- **LNT-002** — slang errors: unknown module/interface/package/primitive, undeclared identifier, import collisions; redefinition warnings. Exempt: none. Severity: slang's severity (ERROR for unresolved references). Unknown: unresolved reference = ERROR and elaboration INCOMPLETE.
- **LNT-003** — slang errors: unknown, duplicate, mixed ordered/named, too many or dimension-mismatched port connections; net-type and implicit-type mismatches. Exempt: none (unconnected ports are LNT-010). Severity: slang's severity. Unknown: as LNT-002.
- **LNT-004** — slang width-trunc/expand, port-width-*, implicit-conv warnings (assignments, ports, operators). Exempt: explicit casts (no slang warning). Severity: slang's severity (WARNING). Unknown: n/a (decided by slang).
- **LNT-005** — slang sign-conversion, sign-compare, ineffective-sign warnings. Exempt: explicit casts. Severity: slang's severity. Unknown: n/a.
- **LNT-006** — slang index-oob, range-oob, range-width-oob (constant out-of-range selects). Exempt: dynamic indexes (not decidable). Severity: slang's severity. Unknown: dynamic indexes are not reported (documented slang behaviour).
- **LNT-007** — slang implicit-net and implicit-net-port warnings. Exempt: none. Severity: slang's severity. Unknown: n/a.
- **LNT-008** — module-level net/variable (not a port), integral and not struct/union/array, with a driver, whose statically driven bits leave a gap. Exempt: ports (LNT-024), struct/array/union (LNT-041); totally undriven symbols (slang). Severity: WARNING Established for a gap. Unknown: WARNING Unresolved when a write uses a module-level index (always) or a loop index with a gap; dynamic driver recorded by slang -> Unresolved.
- **LNT-009** — slang multiple-cont-assigns, multiple-always-assigns, mixed-var-assigns and multi-driver errors on variables; plus overlapping continuous drivers on a plain wire none of which can release it (no z literal). Exempt: tri-state buses (any driver with an X/Z literal); instance-output overlaps are LNT-042. Severity: slang's severity for variables; WARNING for nets. Unknown: a driver that may produce z exempts the net, so a bus with an unknown driver is not reported.
- **LNT-010** — slang unconnected-*/empty-* port warnings. Exempt: intentional empty connections are still reported (waive with a reason). Severity: slang's severity. Unknown: black-box ports are reported too (CST-005).
- **LNT-011** — slang unused-* warnings (nets, variables, parameters, ports, typedefs, genvars, arguments). Exempt: slang honours (* unused *)/(* maybe_unused *) without recording it. Severity: slang's severity. Unknown: n/a.
- **LNT-012** — strongly-connected components of the combinational dependency graph (through ports and hierarchy) and one-node self dependencies. Exempt: paths through registers. Severity: ERROR for a cycle across processes/assigns; WARNING (heuristic) when the cycle exists inside one procedure (statement order is not modelled). Unknown: wide signals tracked as one node are reported as heuristic WARNING.
- **LNT-013** — slang inferred-latch (always_comb) and the order-insensitive latch diagnostics. Exempt: always_latch. Severity: slang's severity. Unknown: legacy always @* latches are not analysed by slang.
- **LNT-014** — slang errors: blocking timing in always_ff, always_ff without exactly one event control, fork-join in always_comb, always without timing. Exempt: none. Severity: ERROR. Unknown: n/a.
- **LNT-015** — blocking assignment to module-level state in a clocked block; nonblocking assignment in a combinational block; one variable assigned with both styles. Exempt: block-local temporaries; always_latch; initial/final. Severity: WARNING. Unknown: n/a.
- **LNT-016** — casex; a casez/casex item whose bits are all wildcards; slang case-default, case-incomplete, case-not-wildcard, case-wildcard-2state, case-none. Exempt: default arm present for case-default. Severity: WARNING. Unknown: n/a.
- **LNT-017** — slang case-enum / case-enum-explicit: an enumerator of an enum-typed case expression has no explicit arm. Exempt: default arm does not satisfy case-enum-explicit. Severity: slang's severity. Unknown: non-enum encodings fall under LNT-016 (case-incomplete).
- **LNT-018** — An if or ?: condition that evaluates to a constant (evalConst) leaves a branch unreachable; a constant case expression leaves an arm or default unreachable. Exempt: generate-if (not statements, so not visited; LNT-051); loop conditions (not if/?:/case); a constant-true if with no else (nothing unreachable). Severity: WARNING for a literal-only constant; INFO when the condition references a parameter, genvar or variable; INFO for a lone 0/1 literal in an if (disable idiom); ?: in parameter initializers is reported as INFO like other configuration-dependent conditions. Unknown: constant case expression with a non-constant item: WARNING Unresolved; constant condition with a pattern or several conditions: WARNING Unresolved.
- **LNT-019** — # delays (statement, intra-assignment, continuous), wait / wait fork / wait_order, fork/join*, disable fork, ->, force/release, procedural assign/deassign, forever, for/repeat/while/do-while with non-constant bound, initial, class / program / covergroup declarations, real/shortreal/string/chandle/dynamic/queue/associative variables. Exempt: assertions: no finding; code in final blocks: INFO; class properties (reported through the class). Severity: WARNING; initial is INFO when profile is fpga; final-block code is INFO. Unknown: non-constant bound containing a user function call: Unresolved; other non-constant bounds: Established.
- **LNT-020** — (a) register assigned only in the reset branch; (b) register assigned only outside the reset branch (no reset value); (c) always_ff with no reset in a module whose other always_ff blocks reset. Exempt: reset = edge control tested by the first if / else-if chain (else: name heuristic); (c) only when a sibling always_ff of the same module resets. Severity: WARNING for (a), (b); INFO for (c). Unknown: unmatched reset or compound test: reset branch taken as if true branch, Heuristic.
- **LNT-022** — (1) one signal in both posedge and negedge of one event list; (2) two or more distinct edge signals where fewer than all-but-one are tested by the first if/else-if chain. Exempt: edge signals tested by the if chain count as async resets (set + reset accepted). Severity: WARNING Established for (1); WARNING Heuristic for (2), message names the clock-like controls. Unknown: unrecognised controls: Heuristic.
- **LNT-024** — output port of a module: never driven at all, or undriven bit range / struct member / array element. Exempt: input and inout ports; dynamic containers. Severity: Established WARNING for "never driven" and undriven bits/members. Unknown: WARNING Unresolved for a module-indexed write (always) or loop-indexed write with a gap.
- **LNT-025** — two sibling if statements without else that assign one whole variable in a combinational procedure, with non-exclusive conditions: the later one silently wins. Exempt: conditions on one identifier compared with different constants; unconditional overwrites are LNT-053. Severity: WARNING (heuristic: the conditions may still be exclusive). Unknown: a call in a condition keeps the finding.
- **LNT-026** — (a) sized literal whose digits need more bits than its size, outside a concatenation; (b) unsized literal compared with an operand wider than 32 bits; (c) constant literal assigned to a narrower target that changes its value under either signedness. Exempt: (a) inside a concatenation/replication: LNT-056; fill literals ('0, '1, 'x, 'z) are not IntegerLiteral and are ignored; shift counts are slang's. Severity: (a) WARNING Established; (c) WARNING Established; (b) INFO Heuristic. Unknown: digits not in one source buffer, or decimal digits containing x/z/? or wider than 128 bits: WARNING Unresolved "could not be checked".
- **LNT-027** — a clock that reaches the data input of a register or an output; a reset that reaches the logic generating a clock. Exempt: clock-gating logic that only feeds clock pins. Severity: WARNING. Unknown: clocks reaching black boxes are not followed.
- **LNT-029** — enum-typed state registers used as a case expression: states never assigned (dead) and arms without any transition (stuck candidates). Exempt: states assigned from non-constant sources suppress the dead-state finding. Severity: WARNING (heuristic) for dead/stuck candidates; INFO with proof state NOT_ATTEMPTED for every FSM (reachability and liveness are never proven). Unknown: unknown sources -> no dead-state claim, obligation remains.
- **LNT-031** — slang errors: assignment to a net in a procedural context, to a const, to a non-variable lvalue; illegal force/procedural-assign targets. Exempt: none. Severity: ERROR. Unknown: n/a.
- **LNT-032** — case inside items whose value ranges overlap (a value matches two items). Exempt: non-overlapping items. Severity: WARNING Established (inside overlap). Unknown: WARNING Unresolved for a non-constant inside item.
- **LNT-033** — unique, unique0 or priority on a case or if statement. Exempt: unique0 has no coverage check; priority has no overlap check; a case with a default has no coverage check. Severity: ERROR Established: overlapping case items (unique/unique0); two or more constant-true unique if conditions. WARNING Established: uncovered values of unique/priority case without default (a four-state selector adds X/Z); unique/priority if without final else. INFO Unresolved: non-constant item or condition, or selector wider than 16 bits when coverage is needed. Unknown: INFO Unresolved (see severity).
- **LNT-034** — ConditionalExpression arms of different width (both non-literal, or one sized literal), or mixed signedness where a signed arm can carry a negative value into an unsigned result. Exempt: fill literals ignored; unsized based literal ('h5) has an explicit 32-bit unsigned type and is not compared on width; a non-negative decimal literal against an unsigned arm is not a sign hazard. Severity: width/sign WARNING Established (one finding per conditional); unsized decimal literal (32-bit signed) vs non-literal arm wider than 32 bits INFO Established. Unknown: arms without integral width are skipped (not bit-width expressions).
- **LNT-035** — (a) unsized literal as left operand of <</<<< in a self-determined position (concatenation or replication operand) whose 32-bit result is widened by the container or the enclosing assignment target to more than 32 bits: WARNING Heuristic; (b) signed non-constant left shift whose context widens the operand: INFO Heuristic. Exempt: context-determined shifts such as wide64 = 1 << n are NOT reported (IEEE 1800 expression sizing gives the literal the context width; fixture good_context_widened pins this); constant operands and constant amounts; >> on signed values (slang's warning); fill literals. Severity: as marked in the trigger. Unknown: none needed; non-integral operands are skipped.
- **LNT-036** — (a) * whose evaluated width is less than the sum of its operands' bits (constant operands count their significant bits): WARNING Heuristic "product truncated"; (b) +/- directly inside a concatenation/replication, both operands non-constant, result as wide as the widest operand (carry lost): WARNING Heuristic; (c) only with option LNT-036.report_modular=true: +/- assigned at exactly the operand width, both operands non-constant: INFO Heuristic. Exempt: constants; non-integral (real) arithmetic; known limitation: (b) also fires on zero-extended operands such as {1'b0,a}+{1'b0,b} inside a concatenation, where no carry is lost. Severity: as marked in the trigger. Unknown: none needed.
- **LNT-037** — slang divide-by-zero (constant divisor zero). Exempt: variable divisors (not decidable). Severity: slang's severity. Unknown: variable divisors are not reported.
- **LNT-038** — Comparison (==, !=, ===, !==, <, <=, >, >=) of a runtime identifier/select with itself, or of a runtime identifier/select with a constant outside the operand's value range (domain computed for signed and unsigned operands, including signed operand vs unsigned constant); a && !a and a. Exempt: . Severity: !a. Unknown: operands that are constant (LNT-018 domain); operands with calls, arithmetic or side effects; X/Z and real constants (LNT-040 / not analysed here).
- **LNT-039** — assignment RHS, conditional-operator arm, or case-default assignment that contains an x or z literal. Exempt: case-default assignment: INFO (don't-care); 'z assigned to a net: INFO (tri-state); comparison operands belong to LNT-040; final/assertions: INFO. Severity: WARNING for other x/z literals; INFO for default and tri-state. Unknown: none needed (literal-only detection).
- **LNT-040** — x/z literal in an ==/!= operand, a non-casez/casex case item, an inside set, or a 1-bit if / ?: condition; === / !== anywhere. Exempt: casez/casex items (wildcards); ==? / !=?; final/assertions: INFO. Severity: WARNING, Established. Unknown: none (literal-only).
- **LNT-041** — module-level packed/unpacked struct, union, fixed unpacked array or multi-dim packed array with some members/elements driven and others not; interface-instance member read but never driven. Exempt: ports (LNT-024); plain vectors (LNT-008). Severity: Established WARNING (member/element never driven; interface member read and never driven). Unknown: WARNING Unresolved for module-indexed writes (always) or loop-indexed write with a gap.
- **LNT-042** — output port connected to a net/variable: overlaps another continuous driver or output port on the same bits; or covers a strict slice while other bits have no driver. Exempt: nets of type tri, triand, trior, tri0, tri1, trireg, wand, wor; drivers whose RHS contains a 'z literal; procedural drivers are not compared. Severity: WARNING Established for overlap (reported at the later driver); INFO Established for partial drive through hierarchy. Unknown: WARNING Unresolved when a non-constant index writes an output-connected symbol.
- **LNT-043** — as LNT-025 for nonblocking assignments in a clocked procedure (overlapping updates to one register). Exempt: as LNT-025. Severity: WARNING (heuristic). Unknown: as LNT-025.
- **LNT-044** — a module-level variable read before its first assignment in an always block that assigns it later (textual order; comb: any whole assignment, clocked: blocking only). Exempt: block-local temporaries; nonblocking reads (old value by design); self-update counters with no later assignment. Severity: WARNING. Unknown: reads on a path that skips an assignment are latch inference (LNT-013), not this rule.
- **LNT-045** — always @(a or b ...) with no edges: a module-level signal read before any blocking whole write in the body but missing from the list (WARNING); a listed signal never read by the body (INFO). Exempt: always @*, always_comb, always_latch, edge lists; block-local variables; element and member reads count as the whole base symbol. Severity: WARNING Established for missing signals; INFO for listed-but-unread signals. Unknown: body calls a user subroutine: WARNING Unresolved (signals read inside it are not checked, INFO suppressed); non-plain sensitivity entry: WARNING Unresolved.
- **LNT-047** — edge event in a sequential block that is (a) an expression with an operator, or (b) a signal driven by a continuous assign, always_comb or level always whose RHS is not a plain signal. Exempt: ports; flop outputs (always_ff or edge-triggered drivers); plain aliases (assign g = clk;, selects of a signal). Severity: WARNING; Established for (a), Heuristic for (b). Unknown: no analysis object in the design: Unresolved.
- **LNT-048** — module-level registers with a declaration initialiser or assigned in an initial block. Exempt: none. Severity: WARNING for asic and generic profile (generic = Unresolved: depends on target), INFO for fpga. Unknown: profile generic keeps it unresolved.
- **LNT-049** — unpacked-array memories with more than one write process or written combinationally (WARNING); read asynchronously, or read and written in one clocked process (INFO: target-dependent semantics). Exempt: single clocked writer. Severity: WARNING (heuristic) / INFO (informational). Unknown: vendor RAM semantics are an obligation (proof NOT_ATTEMPTED), not modelled.
- **LNT-050** — slang errors: assignment to an input, inout declared as variable, illegal modport use, direction on interface ports. Exempt: none. Severity: ERROR. Unknown: n/a.
- **LNT-051** — generate if/case branch not elaborated in this configuration. Exempt: loop generate blocks. Severity: INFO Informational per uninstantiated branch (with the condition value); WARNING Established when no branch of a construct is elaborated. Unknown: n/a (slang elaboration is exact for the configuration).
- **LNT-052** — an else-if chain of at least three arms assigning one register; a register assigned only under a condition in a clocked block (inferred enable). Exempt: reset branches. Severity: INFO (informational). Unknown: n/a.
- **LNT-053** — a whole-variable write overwritten before it is read on at least one path (path-aware walk over blocks, if, case); the overwriting write must sit in the same or an enclosing statement list. Exempt: partial targets; reads or timing controls in between; the default-then-override idiom (q <= 0; if (en) q <= d). Severity: WARNING (Established within one list, Heuristic across branches). Unknown: a subroutine call between the writes -> Unresolved; loops and unrecognised statements clear pending writes.
- **LNT-054** — a register with no reset (event or synchronous pattern) and no initialiser that is read in an if/case/?: condition. Exempt: registers also assigned with a reset elsewhere. Severity: WARNING (heuristic). Unknown: n/a.
- **LNT-055** — (a) a variable that is decremented (-, --, -=, or assigned a subtraction) and compared < 0 or <= -1 (signed) while unsigned; direct form (x - n) < 0 on an unsigned difference: WARNING Established; (b) a variable incremented (+ 1, ++, += 1) and compared with ==, >= or > against a constant the width cannot reach ("guard unreachable, counter wraps"): WARNING Established. Exempt: signed counters; negative constants; comparisons whose other side is non-constant (not analysed, see note). Severity: as marked in the trigger. Unknown: WARNING Established only for proven contradictions; a non-constant guard is NOT reported (deviation: no Unresolved finding, see note).
- **LNT-056** — (a) a RHS concatenation/replication whose operands are all constant and whose width differs from the assignment target: WARNING Established; (b) a sized literal whose digits need more bits than its size, inside a concatenation or replication: WARNING Established. Exempt: unsized literals (slang's unsized-concat); non-constant concatenations; zero or negative replication outside a concatenation is rejected by slang as an error (LNT-001), so no native check is needed. Severity: WARNING Established. Unknown: digits not in one buffer or undecidable: WARNING Unresolved (shared detector with LNT-026).
- **LNT-057** — truncation at a non-compound assignment or at an input/output port connection, where the needed width of the source is larger than the target and a side's declared dimension text names a parameter or type parameter in its scope chain: WARNING Heuristic, message lists the instance's parameter values. Exempt: +, - and bitwise results need only their widest operand's bits (so cnt <= cnt + 1 with an unsized 1 is not a truncation); InOut/Ref ports; compound assignments. Severity: WARNING Heuristic. Unknown: declaration text not available in one buffer: WARNING Unresolved "could not determine parameter dependence".
- **LNT-058** — async reset event of a sequential block: (a) polarity mismatch (negedge with reset branch on high, posedge with reset branch on low); (b) reset not tested by the first if; (c) reset branch assigns a non-constant value. Exempt: blocks with several async controls are skipped; compound tests get no polarity check; (c) skipped when polarity is already mismatched. Severity: (a) ERROR; (b) WARNING Heuristic (reset chosen by name); (c) WARNING. Unknown: non-constant RHS containing a user call: Unresolved.
- **LNT-059** — slang unused-import, unused-package-*, shadow-*, dup-import warnings. Exempt: none. Severity: slang's severity. Unknown: n/a.
- **LNT-060** — a register assigned with a blocking assignment in one clocked process and read in another. Exempt: nonblocking assignments; reads in the writing process. Severity: WARNING. Unknown: races through subroutines/hierarchical references are not followed.
- **LNT-061** — any system subroutine call in user code, and elaboration-time $fatal/$error/$warning/$info. Exempt: allow-list ($clog2 $bits $signed $unsigned $size $high $low $left $right $increment $dimensions $countones $onehot $onehot0 $isunknown $typename $cast); option LNT-061.allow extends it; elaboration-time messages are INFO. Severity: WARNING for known simulation-only calls; INFO for calls in final blocks or assertions; INFO for elaboration-time messages. Unknown: unrecognised system name: WARNING, Unresolved (e.g. $countbits).
